## 研究 / Research

**历史城市形态与道路网络量化**
把 256 座清代县城的道路网从历史地图逐条数字化，提出"规整—有机指数"（Geometric–Organic Index, GOI），用可计算的数字区分"被规划出来的城"与"自己长出来的城"；结合历史 GIS 与 NetLogo 多智能体模拟，重建清代城市路网与空间演变。

**文化遗产无损检测**
探地雷达 + 三维激光扫描 + 人工智能识别。在北京密云 1:1 仿真长城试验平台承担模型搭建、设备联调、数据标注与算法优化全流程，实现墙体内部空洞、裂隙、沉降的可视化表达。
点云算法方向：PointNet 特征提取 · PINN 约束几何重建 · DBSCAN 构件分割 · 三维点云自动转二维图纸。
